ScyllaDB Cloud Engineering – Home
Assignment
Description
Build a simplified DBaaS layer (Database as a Service) for ScyllaDB on one of the leading
cloud providers - AWS, GCP, Azure or OCI.
The system should allow a user to create and operate a 3 VM ScyllaDB cluster through a
simple web interface and API. Use Ubuntu 24 LTS as a VM image, install scylla manager and
scylla promethues/grafana monitor as docker instances on a separate VM.
The system should address:
● Provisioning and lifecycle management of a ScyllaDB cluster.
● Monitoring and recovery from component failures.
● Backup to cloud object storage and restore from backup.
● Monitoring and observability.
● Logging and auditing of important operations and events.
● An API supporting the functionality exposed through the UI.
● CI for the solution.
You may use ScyllaDB Manager and other existing ScyllaDB or cloud-provider capabilities
where appropriate.
What we are looking for
We are interested in seeing how you approach the problem, including:
● A demoable solution
● Architecture and design choices.
● Trade-offs and prioritization.
● The combination of man and machine(s) is a critical success factor in this
homework and at the job. Provide explanation about your prompts, plans, multi
agent instructions, html presentations generated by AI about the plan, the quality, the
missing items.
● Bonus: create a small client to connect to the created cluster over CQL and insert and
read some arbitrary data from the ScyllaDB cluster.
Please document important assumptions, design decisions, limitations, and anything you would
approach differently in a production implementation.
Suggested time investment: 2-3 days with more Claude activity or 1 week with sparse
instructions to Claude/agents
