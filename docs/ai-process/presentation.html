Scylla DBaaS · Plan v1 · 04

The Control Plane never SSHes into nodes: Terraform creates VMs, cloud-init configures them, and day-2 operations go through the Scylla Manager API and Scylla REST API. The Provider interface lets the same Control Plane run against Docker containers locally and in CI.

Monitor Node · t3.xlarge · Docker

Scylla Manager (backup, repair) · Prometheus · Grafana · Loki — stores no data

S3 bucket

clusters/<id>/ · SSE · 30-day lifecycle

RF=3 + QUORUM: the Cluster keeps serving with one Data Node down. Ubuntu 24.04 everywhere; access only from the operator IP; shell via SSM.

Scylla DBaaS · Plan v1 · 05

Open ports, operator CIDR only: 9042 CQL, 10000 Scylla REST, 3000 Grafana, 5080 Manager API. Inter-node traffic stays inside the Security Group. The Cluster password is generated at creation and stored in Secrets Manager.

Scylla DBaaS · Plan v1 · 07

Edge case settled in grilling: losing only the Monitor Node makes the Cluster Degraded, not Healthy, because Backups and metrics stop even though data is fully available. Deleting and Deleted are terminal lifecycle states not shown on the diagram.

Scylla DBaaS · 08

Health is judged from two views: the cloud (is the instance running?) and Scylla itself (do peers see the node as Up/Normal?). A Node Replacement keeps the node’s network interface and Elastic IP, so seeds, Prometheus targets and Manager’s host list stay valid.

Backup and Restore

Restore never touches a live Cluster

1

2

S3

Encrypted, outlives the Cluster

3

New Cluster: schema, then data

4

Scheduled Backups are taken by Manager itself; the Control Plane mirrors them every ~5 minutes and marks retention-purged ones Deleted.

Scylla DBaaS · 09

Why a new Cluster: Scylla Manager restores schema only into an empty cluster, and restoring next to the original avoids any risk to live data (ADR-0005). The mirroring of scheduled Backups was a gap spotted during integration and added afterwards.

Scylla DBaaS · 13

Lessons: a mock encodes the author's belief about an API, so it cannot catch a wrong belief; only the real system can. One green run proves little for async code. Consumers find contract bugs that authors miss. Full log with cause and fix for all 18 in docs/ai-process/mistakes.md.
