Scylla DBaaS · Plan v1 · 04

The Control Plane never SSHes into nodes: Terraform creates VMs, cloud-init configures them, and day-2 operations go through the Scylla Manager API and Scylla REST API. The Provider interface lets the same Control Plane run against Docker containers locally and in CI.
